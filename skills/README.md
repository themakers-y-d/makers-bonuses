# סקילים למערכת MAKERS

כל תיקייה כאן היא סקיל אחד, מוכן להתקנה במערכת שלך.

## איך מתקינים

מעתיקים את תיקיית הסקיל כולה לתוך `.claude/skills/` במערכת שלך, ופותחים מחדש את קלוד קוד. סקילים נטענים בעלייה.

לדוגמה, במערכת שיושבת על שולחן העבודה:

```
MAKERS/.claude/skills/connect-ig-dm/SKILL.md
```

אחרי זה פשוט מבקשים ממורטי את מה שהסקיל עושה, במילים שלך. הוא יזהה ויפעיל.

## מה יש כאן

### connect-ig-dm

מחבר את אוטומציית התגובה-להודעה באינסטגרם: מישהו מגיב מילה על ריל, על פוסט או בתשובה לסטורי, ומקבל הודעה פרטית עם הלינק. אפשר לבקש שיעקוב לפני שהלינק יוצא.

אומרים למורטי "תחבר לי אוטומציית DM לאינסטגרם" והוא לוקח מכאן.

הסקיל עובד יחד עם הערכה בתיקיית [ig-dm-automation](../ig-dm-automation/), אז כדאי לשכפל את הריפו הזה ולא רק להוריד קובץ בודד.

## ממי זה

מבית MAKERS, הסדנה שבונה לך צוות סוכנים שעובד בשבילך: [themakers.co.il](https://themakers.co.il)
