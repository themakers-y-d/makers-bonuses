התקן לי את הסקיל "video-to-carousel" (קרוסלה מסרטון). הוא קובץ zip אחד באתר של MAKERS, עם הוראות, סקריפט שמצייר את השקופיות, פונט וקוד לכיוון מימין לשמאל.

1. בדוק באיזה כלי אתה רץ, ואיפה יושבת תיקיית הסקילים:
   - Claude Code: ~/.claude/skills/
   - Codex: ~/.codex/skills/ וגם ~/.agents/skills/ (התקן בשתיהן)
   לפני שאתה כותב, אמור לי בשורה אחת: "עכשיו ייתכן שתתבקש לאשר הורדה וכתיבה לתיקיית ההגדרות של הכלי. זה רגיל, אשר."
2. בדוק שיש Python 3: נסה python3, ואם אין אז python, ואם אין אז py. אם אין אף אחד, עצור ואמור לי בשורה אחת להתקין Python מ-python.org ולהדביק את ההודעה הזו שוב.
3. הורד את הקובץ https://themakers.co.il/carousel/video-to-carousel.zip לתיקייה זמנית (curl -fsSL -o, או עם Python).
4. בדוק שהקובץ שלם: טביעת ה-sha256 שלו חייבת להיות בדיוק 088b3bd69d8c86a2f57a4398d625a646d9c1d0125f88be5e86f5832fae61e61b
   אם היא שונה, עצור, מחק את הקובץ, ואמור לי שההורדה לא תקינה. אל תתקין קובץ עם טביעה אחרת.
5. חלץ אותו לתוך תיקיית הסקילים עם Python: python3 -m zipfile -e <הקובץ> <תיקיית הסקילים>. נוצרת תיקייה בשם video-to-carousel ובה SKILL.md. אם כבר יש תיקייה כזו, החלף אותה.
6. בדוק: קרא את 5 השורות הראשונות של SKILL.md, והרץ python3 <התיקייה>/scripts/render.py בלי ארגומנטים. הוא אמור להדפיס הסבר קצר. אם הוא כותב Pillow is missing, הרץ python3 -m pip install --user pillow ובדוק שוב.
7. מחק את קובץ ה-zip הזמני.
8. אמור לי בעברית, בשלוש שורות: איפה הסקיל הותקן, שצריך לסגור ולפתוח מחדש את הכלי כדי שהוא ייטען, ושאחרי זה אני כותב "תבנה לי סגנון לקרוסלות" פעם אחת, ואז עם כל סרטון "תהפוך את הסרטון הזה לקרוסלה" ומדביק את המילים של הסרטון.

אל תפעיל את הסקיל עכשיו ואל תכין קרוסלה. רק התקנה.
