# סקיל הקרוסלה מסרטון

סקיל שהופך סרטון שכבר צילמתם לקרוסלה לאינסטגרם, במילים שלכם. הוא קורא את המילים של הסרטון, מוצא בו רעיון אחד, כותב פתיח, ארבע עד שש שקופיות וסוף, ובודק שכל שקופית נשענת על משפט שבאמת אמרתם.

הסקיל לא מפרסם כלום. אתם קוראים, מתקנים אם צריך, ומפרסמים.

## באפליקציה של Claude או באתר

אותו דבר במק ובווינדוס. את ההתקנה עושים מהמחשב, לא מהטלפון.

1. מורידים את [video-to-carousel.zip](https://themakers.co.il/carousel/video-to-carousel.zip). במק, אם ספארי פתח אותו לתיקייה בשם video-to-carousel, לוחצים עליה קליק ימני ובוחרים Compress. זה מכווץ אותה בחזרה לקובץ zip אחד ולא מוחק כלום, ואת הקובץ החדש שנוצר לידה מעלים. בווינדוס מעלים את הקובץ כמו שהוא, בלי לחלץ אותו.
2. ב-Claude לוחצים על העיגול עם האות הראשונה של השם שלכם, בתחתית התפריט שבצד, ובוחרים Settings. ברשימה שבצד מסך ההגדרות נכנסים ל-Capabilities, ומוודאים שהמתג "Create and edit files" דולק. סקילים עובדים רק כשהוא דולק.
3. נכנסים ל-Customize ואז Skills, לוחצים על הפלוס, בוחרים Upload a skill ומעלים את הקובץ. הסקיל video-to-carousel מופיע ברשימה.

## ב-Claude Code או ב-Codex

1. פותחים את הקובץ [INSTALL.md](INSTALL.md) ולוחצים על כפתור ההעתקה בפינה העליונה שלו.
2. מדביקים לקלוד קוד או לקודקס. הוא מתקין את הסקיל לבד. אם הוא מבקש אישור לכתוב לתיקיית ההגדרות שלו, מאשרים.
3. סוגרים ופותחים מחדש את הכלי.

## ואז, עם כל סרטון

1. מוציאים את המילים של הסרטון: התסריט שממנו קראתם, או תמלול חינמי ב-turboscribe.ai (נרשמים בחינם, מעלים את הסרטון, בוחרים עברית ומעתיקים את הטקסט. שלושה סרטונים ביום, עד 30 דקות כל אחד).
2. כותבים "תהפוך את הסרטון הזה לקרוסלה" ומדביקים את הטקסט. הסקיל שואל שתי שאלות בהודעה אחת, ומחזיר בלוק טקסט אחד.
3. מעתיקים את הבלוק, נכנסים ל-[themakers.co.il/carousel/studio](https://themakers.co.il/carousel/studio), מדביקים, בוחרים צבע ומורידים את התמונות. הטקסט לא נשלח לשום מקום, הכל קורה בדפדפן.

## מה יוצא בסוף

שש עד שמונה תמונות בגודל 1080 על 1350, מוכנות לפוסט קרוסלה באינסטגרם, וכיתוב לפוסט. ליד הבלוק הסקיל כותב מאיזה משפט בסרטון באה כל שקופית.
