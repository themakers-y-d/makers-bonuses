# סקיל הקרוסלה מסרטון

סקיל שהופך סרטון שכבר צילמתם לקרוסלה מעוצבת לאינסטגרם, במילים שלכם ובסגנון שלכם. הוא קורא את המילים של הסרטון, בוחר את המסר הכי חזק שאמרתם, כותב פתיח, ארבע עד שש שקופיות וסוף, מצייר אותן כתמונות, ובודק שכל שקופית נשענת על משפט שבאמת אמרתם.

הסקיל לא מפרסם כלום. אתם קוראים, מתקנים אם צריך, ומפרסמים.

## מה יש בתיקייה

`SKILL.md` ההוראות. `styles.md` חמשת המראים, שאלות הסגנון והפורמט של "הסגנון שלי". `scripts/render.py` הסקריפט שמצייר את השקופיות, עם קוד הכיוון מימין לשמאל בתיקייה `scripts/vendor` (python-bidi 0.4.2 ו-six, כל אחד עם הרישיון שלו). `fonts/` הפונט Assistant, ברישיון OFL.

## באפליקציה של Claude או באתר

אותו דבר במק ובווינדוס. את ההתקנה עושים מהמחשב, לא מהטלפון.

1. מורידים את [video-to-carousel.zip](https://themakers.co.il/carousel/video-to-carousel.zip). במק, אם ספארי פתח אותו לתיקייה בשם video-to-carousel, לוחצים עליה קליק ימני ובוחרים Compress, ואת הקובץ החדש שנוצר לידה מעלים. בווינדוס מעלים את הקובץ כמו שהוא, בלי לחלץ אותו.
2. ב-Claude לוחצים על העיגול עם האות הראשונה של השם שלכם, בתחתית התפריט שבצד, ובוחרים Settings. ב-Capabilities מוודאים שהמתג "Create and edit files" דולק. הסקיל מצייר בעזרתו את התמונות.
3. נכנסים ל-Customize ואז Skills, לוחצים על הפלוס, בוחרים Upload a skill ומעלים את הקובץ. הסקיל video-to-carousel מופיע ברשימה.

## ב-Claude Code או ב-Codex

1. פותחים את הקובץ [INSTALL.md](INSTALL.md) ולוחצים על כפתור ההעתקה בפינה העליונה שלו.
2. מדביקים לקלוד קוד או לקודקס. הוא מוריד את הקובץ, בודק שהוא שלם ומתקין. צריך Python 3 במחשב.
3. סוגרים ופותחים מחדש את הכלי.

## פעם אחת: הסגנון שלכם

כותבים "תבנה לי סגנון לקרוסלות". חמש שאלות קצרות, ובסוף בלוק "הסגנון שלי". באפליקציה של Claude שומרים אותו בהוראות של פרויקט בשם "קרוסלות". ב-Claude Code או Codex הוא נשמר לבד ב-`~/carousels/my-style.md`. כבר כתבתם בריף עיצוב לעסק (`brief.md` ו-`tokens.css`)? מצרפים אותם, והסקיל לוקח מהם את הצבעים והחוקים.

## ואז, עם כל סרטון

1. מוציאים את המילים של הסרטון: התסריט שממנו קראתם, או תמלול חינמי ב-turboscribe.ai (נרשמים בחינם, מעלים את הסרטון, בוחרים עברית ומעתיקים את הטקסט. שלושה סרטונים ביום, עד 30 דקות כל אחד).
2. כותבים "תהפוך את הסרטון הזה לקרוסלה" ומדביקים את הטקסט.
3. מורידים את התמונות ומפרסמים.

## מה יוצא בסוף

שש עד שמונה תמונות בגודל 1080 על 1350, מוכנות לפוסט קרוסלה באינסטגרם, כיתוב לפוסט, ושורה לכל שקופית שאומרת מאיזה משפט בסרטון היא באה.
