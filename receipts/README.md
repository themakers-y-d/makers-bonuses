# סקיל הקבלות

סקיל שאוסף מה-Gmail שלכם את הקבלות והחשבוניות של חודש אחד לתיקייה במחשב. כל קובץ נקרא לפי התאריך והשולח, וליד הקבצים נשמרת רשימה אחת לאקסל ולדפדפן. הסקיל רק קורא את המייל: הוא לא שולח, לא מוחק ולא מסמן אף מייל כנקרא.

## ב-Claude Code או ב-Codex

הסקיל צריך לרוץ על המחשב עצמו, כי שם נשמרות הקבלות. לכן הוא עובד ב-Claude Code או ב-Codex, ולא בצ'אט באתר.

1. פותחים את הקובץ [INSTALL.md](INSTALL.md) ולוחצים על כפתור ההעתקה בפינה העליונה שלו.
2. מדביקים לקלוד קוד או ל-Codex. הוא מתקין את הסקיל לבד ואומר מה לעשות אחר כך.
3. פותחים שיחה חדשה וכותבים "תאסוף לי את הקבלות של ספטמבר". בפעם הראשונה הוא מסביר איך יוצרים בגוגל סיסמת אפליקציה, וזה לוקח כמה דקות.

## מה יוצא בסוף

תיקייה בשם קבלות בתיקיית הבית, ובתוכה תיקייה לכל חודש. בה הקבצים, ושתי רשימות של אותו דבר: רשימה.csv לאקסל ורשימה.html לדפדפן.

הסקיל עצמו נמצא ב-[skills/receipts/SKILL.md](../skills/receipts/SKILL.md), והכלי שעושה את העבודה ב-[skills/receipts/collect_receipts.py](../skills/receipts/collect_receipts.py), למי שרוצה לקרוא.

שאלות: makers@themakers.co.il
