1. קודם אמור לי בשורה אחת: "בדרך אבקש ממך לאשר כמה פקודות, וזה רגיל. אם יופיעו שגיאות באדום בבדיקות הראשונות, גם זה רגיל." אחר כך בדוק באיזה מחשב אתה, בלי לשאול אותי: הרץ uname -s. Darwin זה מק. Linux פירושו בדרך כלל שאתה רץ בענן (Claude Code בדפדפן או סשן מרוחק) ולא על המחשב שלי, והסקיל חייב לשבת על המחשב שלי, כי שם יישמרו הקבלות. אמור לי את זה במשפט אחד, ושצריך לפתוח את Claude Code על המחשב עצמו, באפליקציה של Claude למחשב או בטרמינל, ולהדביק שם את ההודעה הזו, ועצור בלי להתקין. אם אני עונה שזה כן המחשב שלי, ממשיכים כמו במק, עם python3.
2. בדוק שיש Python בגרסה 3.8 ומעלה. במק הרץ python3 --version. בווינדוס הרץ py -3 --version, ואם py לא קיים, python --version. גרסה ישנה מ-3.8, או Python 2, נחשבת כאילו אין Python. בווינדוס, ההודעה Python was not found; run without arguments to install from the Microsoft Store פירושה שאין Python. אף פעם אל תריץ python בלי ארגומנטים, כי זה פותח את החנות.
   במק, אם במקום גרסה מופיע xcode-select: note: No developer tools were found, או שנפתח חלון שמציע להתקין command line developer tools: אמור לי שקפץ (או יקפוץ) חלון של אפל, לפעמים מאחורי החלונות האחרים, שבו לוחצים Install (בעברית: התקנה) ולא Get Xcode, ואחר כך Agree (הסכמה), ושההתקנה יכולה לקחת יותר מעשר דקות. כשהיא מסתיימת, מדביקים כאן שוב את הודעת ההתקנה מהדף, זו שהעתקתם בכפתור "העתיקו את הודעת ההתקנה" (אם היא כבר לא בהעתקה, לוחצים על הכפתור שוב). ואם החלון לא נראה, הוא כנראה מאחורי חלון הטרמינל: מזיזים את הטרמינל הצידה. ואמור לי גם: אם לחצת בטעות Not Now (לא עכשיו), פשוט הדבק שוב את אותה הודעת התקנה, והחלון יקפוץ מחדש. עצור.
   בווינדוס, אם אין Python: קודם הרץ winget list --id Python.Python.3.12 --source winget --accept-source-agreements. אם winget עצמו לא מזוהה, עבור ישר לקישור של python.org שלמטה, בלי לבקש אישור ובלי האזהרה על החלון. ואם כבר נתת לי את הקישור הזה בהדבקה קודמת, עבור לפסקה של "כבר הותקן". אם הוא כבר ברשימה, Python הותקן בהדבקה קודמת, ועבור ישר לפסקה של "כבר הותקן" שלמטה. אחרת אמור לי את זה במשפט אחד ובקש אישור להתקין. אחרי שאאשר, אמור לי שייתכן שיקפוץ חלון של ווינדוס שמבקש לאשר שינויים במחשב, לפעמים מאחורי החלונות האחרים, ושם לוחצים Yes (כן). אם לא רואים חלון כזה, מחפשים בשורת המשימות סמל של מגן שמהבהב. ואמור לי שההתקנה לוקחת כמה דקות בלי שום הודעה חדשה, וזה תקין, ושאין צורך לעשות כלום עד שתכתוב לי. אז הרץ winget install -e --id Python.Python.3.12 --source winget --accept-package-agreements --accept-source-agreements, עם זמן המתנה של עד עשר דקות. אם winget חסר, או שההתקנה ב-winget נכשלה (למשל כי לחצתי No בחלון האישור), תן לי את הקישור https://www.python.org/downloads/windows/ ואמור לי להתקין משם את הגרסה האחרונה של Python 3, ואם יש בהתקנה תיבה בשם Add python.exe to PATH, לסמן אותה. בסוף אמור לי לסגור לגמרי את קלוד קוד (או את Codex): בטרמינל לסגור גם את חלון הטרמינל עצמו ולפתוח חלון חדש, ב-VS Code לסגור את כל התוכנה, ובאפליקציה של Claude למחשב לסגור דרך הסמל של Claude ליד השעון (קליק ימני ואז Quit; אם הסמל לא מופיע, לוחצים על החץ הקטן ^ ליד השעון), כי כפתור הסגירה לפעמים רק מסתיר אותה. אחר כך לפתוח מחדש. אחר כך להדביק שוב את הודעת ההתקנה מהדף, זו שהעתקתי בכפתור "העתיקו את הודעת ההתקנה". באפליקציה של Claude למחשב, בלשונית Code, פותחים שיחה חדשה (New session) ומדביקים בה, ולא בשיחה הקודמת. התיקייה שמסומנת ליד תיבת ההודעה לא משנה להתקנה. ועצור.
   כבר הותקן: אם Python הותקן בהדבקה קודמת, או ש-winget אומר שהוא כבר מותקן, אל תתקין שוב ואל תבקש אישור. אמור לי שההתקנה הצליחה, ושהחלון הנוכחי עדיין לא רואה אותה. באפליקציה של Claude למחשב, כפתור הסגירה לפעמים רק מסתיר אותה, ולכן סוגרים דרך הסמל של Claude ליד השעון: קליק ימני ואז Quit (אם הסמל לא מופיע, לוחצים על החץ הקטן ^ ליד השעון). בטרמינל סוגרים גם את חלון הטרמינל, וב-VS Code את כל התוכנה. אחר כך פותחים מחדש ומדביקים שוב את הודעת ההתקנה מהדף, זו שהעתקתם בכפתור "העתיקו את הודעת ההתקנה". באפליקציה של Claude למחשב, בלשונית Code, פותחים שיחה חדשה (New session) ומדביקים בה, ולא בשיחה הקודמת. התיקייה שמסומנת ליד תיבת ההודעה לא משנה להתקנה. אם גם אחרי זה Python לא נמצא, מפעילים מחדש את המחשב ומדביקים שוב, ואם גם אז לא, כותבים ל-makers@themakers.co.il. עצור.
   מכאן והלאה PY הוא python3 במק, ו-py -3 בווינדוס (או python, אם רק הוא החזיר גרסה).
3. הרץ את הפקודה הזו בדיוק כמו שהיא, ורק במקום המילה PY בתחילתה כתוב את מה שמצאת בסעיף 2. היא מורידה את שני הקבצים של הסקיל מגרסה קבועה, ובודקת את טביעת האצבע של שניהם לפני שהיא שומרת משהו:
PY -c "import urllib.request as u,hashlib as h,os,sys;sys.stdout.reconfigure(errors='backslashreplace');B='https://raw.githubusercontent.com/themakers-y-d/makers-bonuses/4631bd7e17ca8cc415f040ceb053d67e96eef639/skills/receipts';F=[('SKILL.md','7c289adfa84e300d401d7d9d033f03c0d7a8a8e9b6945a49eab0aeb79d1e3c89'),('collect_receipts.py','8faf18133c1279c7e65fd17129c85f93e37466b5ddb2785a42383eb7dc08e765')];G=[(n,u.urlopen(B+'/'+n,timeout=60).read(),s) for n,s in F];bad=[n for n,b,s in G if h.sha256(b).hexdigest()!=s];d=[os.path.join(os.path.expanduser('~'),x,'skills','receipts') for x in ('.claude','.agents')];[os.makedirs(p,exist_ok=True) for p in d if not bad];[open(os.path.join(p,n),'wb').write(b) for p in d for n,b,s in G if not bad];print('CHECK FAILED '+' '.join(bad) if bad else 'INSTALLED '+' '.join(d))"
   צריכה לצאת שורה שמתחילה ב-INSTALLED, עם שתי תיקיות: .claude בשביל קלוד קוד ו-.agents בשביל Codex. אם אתה Codex והפקודה נכשלה עם Operation not permitted, nodename nor servname או שגיאת רשת אחרת, זה ארגז החול שלך ולא תקלה: הרץ אותה שוב עם בקשת הרשאה מחוץ לארגז, וזה לא נספר כניסיון. במק, אם השגיאה מזכירה CERTIFICATE_VERIFY_FAILED, הרץ במקומה, פעם אחת, את הפקודה הזו, שמורידה עם curl לתיקייה זמנית, בודקת את טביעת האצבע, ורק אז מעתיקה. צריכות לצאת שתי שורות שנגמרות ב-OK ושתי שורות INSTALLED:

   על כל שגיאה אחרת, או CHECK FAILED, הרץ את אותה פקודה עוד פעם אחת בלבד. אם גם אז זה לא עובר, אמור לי שההורדה לא עוברת, ושאפשר לכתוב ל-makers@themakers.co.il, ועצור.
