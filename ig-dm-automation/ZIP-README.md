# אוטומציית DM באינסטגרם, ערכה למערכת MAKERS

מישהו מגיב מילה על ריל שלך או עונה לסטורי, ומקבל ממך הודעה פרטית עם הלינק תוך שניות. אפשר גם לבקש שיעקוב לפני שהלינק יוצא.

## מה עושים עם התיקייה הזו

גוררים את כל התיקייה `ig-dm-automation-kit` אל `3-work/in` במערכת שלך, ב-Obsidian, ב-Finder במק או בסייר הקבצים בווינדוס. ואז אומרים למורטי:

```
מורטי, שמתי ב-3-work/in את ערכת אוטומציית ה-DM של MAKERS. לך לפי ig-dm-automation/INSTALL-makers.md שבתוכה.
```

מורטי מעביר אותה לתיקייה קבועה מחוץ למערכת, מתקין את הסקיל, ומוביל אותך משם. באמצע הוא יבקש ממך לסגור ולפתוח את קלוד קוד, וייתן לך משפט אחד להדביק כשחוזרים.

## מה יש בפנים

`ig-dm-automation` הערכה עצמה: ההוראות למורטי, הכלי, והמלכודות שהוא מכיר.

`skills/connect-ig-dm` הסקיל שנשאר אצלך במערכת, כדי שבפעם הבאה תגיד "תחבר לי DM אוטומטי באינסטגרם" והוא יידע לבד.

את הקבצים עצמם אין צורך לקרוא. הם כתובים אל מורטי.

## מה צריך מראש

חשבון אינסטגרם עסקי או יוצר, כי חשבון פרטי לא נותן גישה לתגובות ולהודעות. ההחלפה חינמית ולוקחת דקה בהגדרות. עובד במק ובווינדוס.

מבית MAKERS: [themakers.co.il](https://themakers.co.il)
