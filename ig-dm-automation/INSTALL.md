# הוראות התקנה, לקלוד קוד

הקובץ הזה מיועד אליך, הסוכן שמתקין. הבעלים לא צריך לקרוא אותו.

## מה אתה מתקין

מערכת שמזהה מילת מפתח בתגובה על ריל או פוסט, או בתשובה לסטורי, ושולחת למגיב הודעה פרטית עם לינק, ועוד תגובה פומבית קצרה. אופציונלית היא מבקשת מהאדם לעקוב לפני שהלינק יוצא.

המנוע הוא Zernio, שותפה רשמית של מטא. זה החלק שחשוב שתבין: הבעלים **לא** פותח אפליקציית מטא ו**לא** מגיש App Review. הוא מחבר את חשבון האינסטגרם ל-Zernio ומשתמש באישור שלהם. לכן סטורי ושער עוקבים עובדים מהיום הראשון ולא אחרי שבועות של המתנה.

אין שרת, אין מסד נתונים, אין טוקן לתחזק, ואין ג'וב מתוזמן.

## כללי העבודה שלך

זו עבודה על חשבון אינסטגרם אמיתי ושליחת הודעות לאנשים אמיתיים. ארבעה כללים.

לפני כל שלב, הסבר לבעלים במשפט מה עומד לקרות ומה יידרש ממנו.

שתי פעולות הן שלו ולא שלך, ואל תנסה לעשות אותן במקומו: ההרשמה ל-Zernio, ואישור החיבור של אינסטגרם. שתיהן מעניקות גישה לחשבון שלו, וסוכן לא מאשר גישה לחשבון של מישהו אחר. תגיד לו בדיוק מה ללחוץ, ותחכה.

המפתח לא עובר בצ'אט. הוא מוצג פעם אחת על המסך שלו, והוא מדביק אותו לקובץ בעצמו. אם הוא כבר נעלם, מייצרים מפתח חדש. אל תדפיס אותו, גם לא בתוך הודעת שגיאה.

אל תריץ `--apply` לפני שהרצת בלי `--apply` והראית לבעלים את התוצאה.

## סדר העבודה

### שלב 0, קרא קודם

קרא עד הסוף את `04-gotchas.md`. זה קטלוג של תקלות אמיתיות שקרו בהתקנה הזו, והוא יחסוך לך שעות. רוב מה שייראה לך כמו באג כבר מתועד שם.

בדוק שהמכונה מוכנה: `node --version` מחזיר 18 ומעלה.

### שלב 1, שאלות לבעלים

שאל את השלוש בבת אחת, לא מפוזרות על פני השיחה:

• חשבון האינסטגרם שלך מוגדר Business או Creator?

• איזו מילה אנשים יגיבו, ולאן הלינק שולח?

• רוצה שרק עוקבים יקבלו את הלינק, או שכולם?

אם החשבון פרטי, עצור כאן ושלח אותו להפוך אותו לחשבון יוצר בהגדרות אינסטגרם. בלי זה שום דבר בהמשך לא יעבוד, ואין מסלול עוקף.

### שלב 2, חשבון Zernio ומפתח

שלח אותו ל-zernio.com/signup. התחברות עם גוגל היא המהירה ביותר.

מיד אחרי ההרשמה מוצג לו מפתח API, וזו תצוגה חד פעמית. תגיד לו את זה **לפני** שהוא נרשם, כדי שיעתיק אותו ברגע שהוא מופיע.

צור את הקובץ ואת ההרשאות, ובקש ממנו להדביק לתוכו:

```bash
mkdir -p ~/.config/ig-dm && touch ~/.config/ig-dm/zernio.env && chmod 600 ~/.config/ig-dm/zernio.env
```

הקובץ מכיל שורה אחת: `ZERNIO_API_KEY=sk_...`

אל תשים את הקובץ בתיקייה מסונכרנת כמו iCloud או Dropbox, ולא בכונן חיצוני. הרצה מתוזמנת נחסמת משם ונכשלת בשקט, וזה נראה בדיוק כמו באג בקוד.

### שלב 3, חיבור אינסטגרם

בדשבורד של Zernio, בעמוד Connections, הוא בוחר Instagram.

נפתח מסך אישור של אינסטגרם עם חמישה מתגים. תגיד לו לכבות שניים: פרסום תוכן, ותובנות. המערכת הזו לא צריכה אותם, ומינימום הרשאות הוא הרגל טוב. נשארים דלוקים: פרופיל ומדיה, תגובות, והודעות.

הוא לוחץ Allow. זה הקליק שלו.

### שלב 4, אימות שהחיבור חי

```bash
node kit/zernio.mjs doctor
```

צריך להחזיר שהמפתח התקבל, ושיש חשבון אינסטגרם אחד מחובר ופעיל. אם החשבון לא מופיע, חזור לשלב 3.

### שלב 5, בניית החוקים

העתק את `kit/automations.example.json` ל-`kit/automations.json` ומלא לפי התשובות משלב 1.

קרא את `02-rules.md` לפני שאתה בוחר מצב התאמה, ואת `03-copy.md` לפני שאתה כותב נוסח. אל תמציא נוסחים בלי להראות לבעלים; זה הטקסט שאנשים אמיתיים יקראו.

כל מקום שנשאר בו `REPLACE_ME` עוצר את הכלי לפני שנשלחת ולו קריאה אחת, וזה מכוון.

ואז:

```bash
node kit/selfcheck.mjs
node kit/zernio.mjs plan
node kit/zernio.mjs sync --apply
```

הראה לבעלים את הפלט של `plan` לפני שאתה מריץ `sync`.

### שלב 6, אימות שהחוקים באמת נקלטו

אל תסתפק בפלט של `sync`. תקרא חזרה מהשרת:

```bash
node kit/zernio.mjs list
node kit/zernio.mjs get <id>
```

ודא ששדות השער, הכפתורים והווריאציות באמת שם. שדה שנבלע בשקט מתגלה חודש מאוחר מדי, כשליד לא מקבל הודעה.

### שלב 7, בדיקה חיה, ובלעדיה לא סיימת

תגובה של הבעלים על הפוסט של עצמו לא מפעילה כלום. צריך אדם אחר.

תגיד לו לבקש מחבר להגיב את המילה על ריל אמיתי, ואז:

```bash
node kit/zernio.mjs logs <id>
```

רק כשרואים שם שורה עם משלוח מוצלח, ההתקנה הסתיימה. עד אז אתה יודע שההגדרות נכונות, לא שהמסירה עובדת. אל תגיד לבעלים שסיימת לפני זה.

### שלב 8, דרך החזרה

תגיד לו את זה בסוף. זה מרגיע וזה נכון:

```bash
node kit/zernio.mjs pause <id> --apply
```

מפסיק כל שליחה מיידית בלי לפרק כלום, ו-`resume` מחזיר.

## כשמשהו לא עובד

`04-gotchas.md` קודם.

אם זה לא שם, סדר האבחון: האם `doctor` ירוק, האם החוק פעיל, האם המילה באמת מתאימה למצב ההתאמה שבחרת, והאם התגובה הגיעה אחרי שהחוק כבר נוצר. וובהוק הוא קדימה בלבד, ותגובות שקדמו לחוק לא ייתפסו לעולם.
