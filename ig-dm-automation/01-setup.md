# איך זה עובד

## התמונה במשפט

מישהו מגיב מילה, או עונה לסטורי. המערכת מזהה את המילה, שולחת לו הודעה פרטית עם הלינק, וכותבת תגובה פומבית קצרה מתחת לתגובה שלו. אם הפעלת שער עוקבים, היא מבקשת ממנו לעקוב לפני שהלינק יוצא.

המנוע הוא Zernio, פלטפורמה שהיא שותפה רשמית של מטא ומחזיקה את ההרשאות מולה. אתה מחבר אליה את חשבון האינסטגרם שלך ומשתמש בהן.

בפועל: אין אפליקציית מטא לפתוח, אין שרת להקים, אין מסד נתונים, ואין טוקן לתחזק.

## מה יושב אצלך

חשבון Zernio עם חשבון האינסטגרם שלך מחובר אליו. עד שני חשבונות מחוברים זה חינם.

מפתח API בקובץ אחד, `~/.config/ig-dm/zernio.env`. לא בריפו ולא בתיקייה מסונכרנת.

תיקיית `kit/` עם סקריפט אחד וקובץ הגדרות. כל מה שמשתנה יושב ב-`automations.json` ולעולם לא בתוך הקוד.

## ההרשאות

במסך האישור של אינסטגרם יש חמישה מתגים. שלושה נשארים דלוקים: פרופיל ומדיה, תגובות, והודעות.

שניים מכובים: פרסום תוכן, ותובנות. המערכת לא צריכה אותם.

הכלל: לא נותנים הרשאה שלא משתמשים בה. אם יום אחד תרצה שהכלי גם יפרסם, תחבר מחדש ותדליק.

## הפקודות

```bash
node kit/zernio.mjs doctor      # המפתח תקין? החשבון מחובר? הקונפיג שפוי?
node kit/zernio.mjs plan        # מה ישתנה. בלי לכתוב כלום
node kit/zernio.mjs sync --apply
node kit/zernio.mjs list        # מה חי עכשיו, כולל כמה נשלחו
node kit/zernio.mjs get <id>    # כל השדות של חוק אחד, כפי שהשרת מחזיק אותם
node kit/zernio.mjs logs <id>   # מי הגיב, מה כתב, והאם ההודעה יצאה
node kit/zernio.mjs pause <id> --apply
```

כל פקודה מדפיסה מה היא עומדת לעשות לפני שהיא עושה. כתיבה היא dry run עד שמוסיפים `--apply`, ומחיקה דורשת גם `--yes`.

## כשמשהו לא עובד

```bash
node kit/zernio.mjs doctor
```

הוא אומר בשורה אחת אם הבעיה במפתח, בחיבור או בקונפיג. משם `04-gotchas.md`.
