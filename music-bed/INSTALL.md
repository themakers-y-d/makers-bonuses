התקן לי את סקיל המוזיקה של MAKERS: סקיל חינמי לקלוד קוד ששם שיר בלי המילים מתחת לסרטון שלי, והמוזיקה יורדת לבד כשאני מדבר. רק התקנה, בלי להוריד שיר ובלי לגעת בסרטונים שלי עדיין. כל משפט שאתה כותב לי בעברית.

1. קודם אמור לי בשורה אחת: "בדרך אבקש ממך לאשר כמה פקודות, וזה רגיל, מאשרים. אם יופיעו שגיאות באדום בבדיקות הראשונות, גם זה רגיל. החלק הארוך הוא בסוף, ואגיד מתי הוא מתחיל." אחר כך בדוק באיזה מחשב אתה, בלי לשאול אותי: הרץ uname -s. Darwin זה מק. MINGW, MSYS או CYGWIN זה ווינדוס עם Git Bash. אם הפקודה נכשלת, אתה בווינדוס ב-PowerShell, וזה בסדר גמור, ממשיכים.
2. בדוק שיש Python בגרסה 3.8 ומעלה. במק הרץ python3 --version. בווינדוס הרץ py -3 --version, ואם py לא קיים, python --version. גרסה ישנה מ-3.8, או Python 2, נחשבת כאילו אין Python. בווינדוס, ההודעה Python was not found; run without arguments to install from the Microsoft Store פירושה שאין Python. אף פעם אל תריץ python בלי ארגומנטים, כי זה פותח את החנות.
   במק, אם במקום גרסה מופיע xcode-select: note: No developer tools were found, או שנפתח חלון שמציע להתקין command line developer tools: אמור לי שקפץ (או יקפוץ) חלון של אפל, לפעמים מאחורי החלונות האחרים, שבו לוחצים Install (בעברית: התקנה) ולא Get Xcode, ואחר כך Agree (הסכמה), ושההתקנה יכולה לקחת יותר מעשר דקות. כשהיא מסתיימת, מדביקים את ההודעה הזו שוב. ואמור לי גם: אם לחצת בטעות Not Now (לא עכשיו), פשוט הדבק את ההודעה הזו שוב, והחלון יקפוץ מחדש. עצור.
   בווינדוס, אם אין Python: קודם הרץ winget list --id Python.Python.3.12 --source winget --accept-source-agreements. אם winget עצמו לא מזוהה, עבור ישר לקישור של python.org שלמטה, בלי לבקש אישור ובלי האזהרה על החלון. ואם כבר נתת לי את הקישור הזה בהדבקה קודמת, עבור לפסקה של "כבר הותקן". אם הוא כבר ברשימה, Python הותקן בהדבקה קודמת, ועבור ישר לפסקה של "כבר הותקן" שלמטה. אחרת אמור לי את זה במשפט אחד ובקש אישור להתקין. אחרי שאאשר, אמור לי שייתכן שיקפוץ חלון של ווינדוס שמבקש לאשר שינויים במחשב, לפעמים מאחורי החלונות האחרים, ושם לוחצים Yes (כן). אם לא רואים חלון כזה, מחפשים בשורת המשימות סמל של מגן שמהבהב. אז הרץ winget install -e --id Python.Python.3.12 --source winget --accept-package-agreements --accept-source-agreements, עם זמן המתנה של עד עשר דקות. אם winget חסר, או שההתקנה ב-winget נכשלה (למשל כי לחצתי No בחלון האישור), תן לי את הקישור https://www.python.org/downloads/windows/ ואמור לי להתקין משם את הגרסה האחרונה של Python 3, ואם יש בהתקנה תיבה בשם Add python.exe to PATH, לסמן אותה. בסוף אמור לי לסגור לגמרי את קלוד קוד: בטרמינל לסגור גם את חלון הטרמינל עצמו ולפתוח חלון חדש, ב-VS Code לסגור את כל התוכנה, ובאפליקציה של Claude למחשב לסגור דרך הסמל של Claude ליד השעון (קליק ימני ואז Quit; אם הסמל לא מופיע, לוחצים על החץ הקטן ^ ליד השעון), כי כפתור הסגירה לפעמים רק מסתיר אותה. אחר כך לפתוח מחדש. אחר כך להדביק את ההודעה הזו שוב, ועצור.
   כבר הותקן: אם Python הותקן בהדבקה קודמת, או ש-winget אומר שהוא כבר מותקן, אל תתקין שוב ואל תבקש אישור. אמור לי שההתקנה הצליחה, ושהחלון הנוכחי עדיין לא רואה אותה. באפליקציה של Claude למחשב, כפתור הסגירה לפעמים רק מסתיר אותה, ולכן סוגרים דרך הסמל של Claude ליד השעון: קליק ימני ואז Quit (אם הסמל לא מופיע, לוחצים על החץ הקטן ^ ליד השעון). בטרמינל סוגרים גם את חלון הטרמינל, וב-VS Code את כל התוכנה. אחר כך פותחים מחדש ומדביקים את ההודעה הזו שוב. אם גם אחרי זה Python לא נמצא, מפעילים מחדש את המחשב ומדביקים שוב, ואם גם אז לא, כותבים ל-makers@themakers.co.il. עצור.
   מכאן והלאה PY הוא python3 במק, ו-py -3 בווינדוס (או python, אם רק הוא החזיר גרסה).
3. הרץ את הפקודה הזו בדיוק כמו שהיא, ורק במקום המילה PY בתחילתה כתוב את מה שמצאת בסעיף 2. היא מורידה את שני הקבצים של הסקיל מגרסה קבועה, ובודקת את טביעת האצבע של שניהם לפני שהיא שומרת משהו:
PY -c "import urllib.request as u,hashlib as h,os,sys;sys.stdout.reconfigure(errors='backslashreplace');B='https://raw.githubusercontent.com/themakers-y-d/makers-bonuses/COMMIT_AT_GO_LIVE/skills/music-bed';F=[('SKILL.md','c265dcfd7739e660a1ef11ea02802769f44c1ade2be987c73e5d0205810af3f1'),('music_bed.py','0815fb91f15461c7d746481b096510bb590d5b9c3a54e38d1b9d0abb0bf53632')];G=[(n,u.urlopen(B+'/'+n,timeout=60).read(),s) for n,s in F];bad=[n for n,b,s in G if h.sha256(b).hexdigest()!=s];d=os.path.join(os.path.expanduser('~'),'.claude','skills','music-bed');[os.makedirs(d,exist_ok=True) for x in [1] if not bad];[open(os.path.join(d,n),'wb').write(b) for n,b,s in G if not bad];print('CHECK FAILED '+' '.join(bad) if bad else 'INSTALLED '+d)"
   צריכה לצאת שורה שמתחילה ב-INSTALLED. במק, אם השגיאה מזכירה CERTIFICATE_VERIFY_FAILED, הרץ במקומה, פעם אחת, את הפקודה הזו, שמורידה עם curl ומוחקת את שני הקבצים אם טביעת האצבע לא מתאימה. צריכות לצאת שתי שורות שנגמרות ב-OK:
D="$HOME/.claude/skills/music-bed"; mkdir -p "$D" && for f in SKILL.md music_bed.py; do curl -fsSL "https://raw.githubusercontent.com/themakers-y-d/makers-bonuses/COMMIT_AT_GO_LIVE/skills/music-bed/$f" > "$D/$f" || echo "PROBLEM $f did not download"; done; ( cd "$D" && printf '%s  %s\n' c265dcfd7739e660a1ef11ea02802769f44c1ade2be987c73e5d0205810af3f1 SKILL.md 0815fb91f15461c7d746481b096510bb590d5b9c3a54e38d1b9d0abb0bf53632 music_bed.py | shasum -a 256 -c - ) || { rm -f "$D/SKILL.md" "$D/music_bed.py"; echo "CHECK FAILED, nothing was kept"; }
   על כל שגיאה אחרת, או CHECK FAILED, הרץ את אותה פקודה עוד פעם אחת בלבד. אם גם אז זה לא עובר, אמור לי שההורדה לא עוברת, ושאפשר לכתוב ל-makers@themakers.co.il, ועצור.
4. אם תרצה, קרא את שני הקבצים בתיקייה לפני שאתה מריץ אותם. אחר כך הרץ PY "$HOME/.claude/skills/music-bed/music_bed.py" selftest. זו בדיקה בלי אינטרנט, וצריכה לצאת שורה שמתחילה ב-SELFTEST OK. אם יוצא SELFTEST FAILED, אמור לי במשפט אחד שהבדיקה העצמית נכשלה, ושאפשר לכתוב ל-makers@themakers.co.il, ועצור.
5. עכשיו החלק הארוך, פעם אחת בלבד. לפני שאתה מריץ אמור לי: "עכשיו אני מתקין את הכלים שמסירים את השירה מהשיר. זה מוריד כמה מאות מגה, תופס בערך ג'יגה במחשב, ולוקח בין 5 ל-15 דקות, ובאינטרנט איטי יותר. ההתקנה רצה ברקע, ואני אבדוק אותה כל כמה דקות, ולפעמים אבקש אישור להמשיך לבדוק. השאירו את המחשב דלוק ומחובר לחשמל, כי מחשב שנרדם עוצר את ההורדה." אז הרץ PY "$HOME/.claude/skills/music-bed/music_bed.py" setup, עם זמן ההמתנה הארוך ביותר שיש לך (עשר דקות). הפקודה מתחילה את ההתקנה ברקע ומחכה לה עד כשמונה דקות. SETUP OK: ההתקנה הסתיימה. SETUP_RUNNING: ההתקנה עדיין רצה ברקע, וזה תקין. הרץ את אותה פקודה שוב, והיא ממשיכה לחכות לאותה התקנה ולא מתחילה חדשה. עד שמונה הרצות בסך הכל. אם גם אחרי שמונה עדיין SETUP_RUNNING, אמור לי שההתקנה ממשיכה ברקע, ושבשיחה חדשה אכתוב "תבדוק אם סקיל המוזיקה מוכן", ועבור לסעיף 6. LOW_DISK אומר שאין מספיק מקום פנוי: אמור לי כמה צריך, ועצור. SETUP_FAILED: הרץ את הפקודה עוד פעם אחת, כי היא ממשיכה מהמקום שבו עצרה. SETUP_FAILED פעמיים ברצף: אמור לי במשפט אחד מה נכשל, ושאפשר לכתוב ל-makers@themakers.co.il, ועצור. אל תוריד שום שיר ואל תיגע באף סרטון עכשיו.
