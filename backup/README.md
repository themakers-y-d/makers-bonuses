# גיבוי למערכת

מתנה לבעלים של מערכת MAKERS. ההדרכה המלאה, עם השלבים: [themakers.co.il/bonus/backup](https://themakers.co.il/bonus/backup).

## שתי הדרכים לגבות את המערכת

דרך 1, גיבוי מלא בגיטהאב, היא הדרך המומלצת. היא חינם, ומגבה את כל המערכת, כולל הצוות והסקילים, עם היסטוריה בלי תאריך תפוגה. הגיבוי מתעדכן לבד בכל פתיחה של המערכת, ובזמן העבודה לכל היותר פעם בשלוש שעות. מורטי מתקין אותה מהודעה אחת: [INSTALL-makers.md](INSTALL-makers.md). ביום של מחשב חדש, מחזירים את המערכת עם [RESTORE.md](RESTORE.md).

דרך 2, אובסידיאן סינק, מגבה רק את הפתקים. היא עולה 48 דולר לשנה, או 5 דולר בחודש, ושומרת היסטוריה של חודש אחד. הצוות והסקילים לא נכנסים אליה. הבעלים מפעיל אותה בעצמו, בכמה לחיצות בתוך אובסידיאן.

אפשר להפעיל את שתיהן יחד.

## מה שתי הדרכים לא מגבות

1) קבצים מחוץ לתיקיית המערכת: מסמכים, תמונות וסרטונים בשולחן העבודה, בהורדות או בכל מקום אחר.
2) עבודה מהשעות האחרונות, מאז הגיבוי האחרון.
3) סיסמאות ומפתחות. בדרך 1 הם נשארים בחוץ בכוונה.
4) סרטונים וקבצים גדולים: מעל 49 מגה בדרך 1, ומעל 5 מגה במסלול הבסיסי של דרך 2.
5) ההתחברויות לתוכנות ולכלים. ביום של מחשב חדש מתחברים מחדש, והרשימה נמצאת בקובץ tools.md.

## איך מגבים את מה שנשאר

א) את כל המחשב, לדיסק בבית. במק עושים את זה עם Time Machine, ובווינדוס עם File History. זה מכסה את הסרטונים, את הקבצים הגדולים ואת השעות האחרונות. הדיסק צריך להיות גדול לפחות פי שניים מהנפח שתפוס היום במחשב.

ב) מסמכים שאין להם תחליף, לכונן ענן: iCloud Drive, Google Drive או OneDrive. רק לא את תיקיית המערכת עצמה, שצריכה להישאר מחוץ לענן.

ג) סיסמאות ומפתחות, במנהל סיסמאות. שומרים שם את הסיסמה של גיטהאב ואת קודי השחזור שלה, את סיסמת ההצפנה של אובסידיאן, וכל מפתח של כלי שמחברים.

## למורטי: לעזור לבעלים לבחור

כשהבעלים מבקש עזרה בבחירה, שאל עד שלוש שאלות בהודעה אחת: מה הכי חשוב לו לשמור, כמה הוא מוכן לשלם, ומה כבר יש לו (דיסק חיצוני, כונן ענן, מנהל סיסמאות). בדוק בעצמך אם זה מק או ווינדוס, ואל תשאל אותו. אחר כך המלץ על צירוף אחד מתוך מה שכתוב כאן, במשפטים קצרים, והצע להתקין את דרך 1 מיד.
