התקן לי את הסקיל "video-to-skill" (מסרטון לסקיל: הופך מדריך, סרטון, ריל או מאמר לסקיל שעובד). הוא קובץ zip אחד באתר של MAKERS, עם הוראות וסקריפטים.

1. בדוק באיזה כלי אתה רץ, ואיפה יושבת תיקיית הסקילים:
   - Claude Code: ~/.claude/skills/
   - Codex: ~/.codex/skills/ וגם ~/.agents/skills/ (התקן בשתיהן)
   לפני שאתה כותב, אמור לי בשורה אחת: "עכשיו ייתכן שתתבקש לאשר הורדה וכתיבה לתיקיית ההגדרות של הכלי. זה רגיל, אשר."
2. הורד את הקובץ https://themakers.co.il/learn/video-to-skill.zip לתיקייה זמנית, כך שהמעטפת כותבת את הקובץ: curl -fsSL "<הכתובת>" > "<הקובץ>". בלי Python ובלי שום התקנה.
3. בדוק שהקובץ שלם: טביעת ה-sha256 שלו (shasum -a 256 במק, sha256sum בווינדוס ובלינוקס) חייבת להיות בדיוק dccc7bd6d6aeda6d2ea7425d249dd0cd3b1a807eaa7b3258b0a8536cbaf3bc21
   אם היא שונה, עצור, מחק את הקובץ, ואמור לי שההורדה לא תקינה. אל תתקין קובץ עם טביעה אחרת.
4. אם כבר יש תיקייה בשם video-to-skill בתיקיית הסקילים, מחק אותה קודם. אחר כך חלץ: unzip -oq "<הקובץ>" -d "<תיקיית הסקילים>". אם אין unzip (בווינדוס לפעמים), חלץ עם PowerShell: powershell -NoProfile -Command "Expand-Archive -Force '<הקובץ>' '<תיקיית הסקילים>'". נוצרת תיקייה בשם video-to-skill ובה SKILL.md ותיקיית scripts.
5. בדוק: קרא את 5 השורות הראשונות של SKILL.md, וודא שבתיקייה scripts יש get_source.py ו-install-tools.sh.
6. מחק את קובץ ה-zip הזמני.
7. אמור לי בעברית, בשלוש שורות: איפה הסקיל הותקן, שצריך לסגור ולפתוח מחדש את הכלי כדי שהוא ייטען, ושאחרי זה אני כותב "תבנה לי סקיל מהסרטון הזה" עם קישור או קובץ, ובפעם הראשונה הוא יבקש להתקין כלים קטנים לתיקייה אחת בשם reel-studio.

אל תפעיל את הסקיל עכשיו ואל תתקין את הכלים שלו. רק התקנה של הסקיל.
