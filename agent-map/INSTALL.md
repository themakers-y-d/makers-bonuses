התקן לי את הסקיל "agent-map" (המפה של הסוכנים לעסק). הוא קובץ zip אחד באתר של MAKERS, עם הוראות, סקריפט שבונה את המפה כעמוד מעוצב, ופונט.

1. בדוק באיזה כלי אתה רץ, ואיפה יושבת תיקיית הסקילים:
   - Claude Code: ~/.claude/skills/
   - Codex: ~/.codex/skills/ וגם ~/.agents/skills/ (התקן בשתיהן)
   לפני שאתה כותב, אמור לי בשורה אחת: "עכשיו ייתכן שתתבקש לאשר הורדה וכתיבה לתיקיית ההגדרות של הכלי. זה רגיל, אשר."
2. בדוק שיש Python 3: במק ובלינוקס נסה python3 --version. בווינדוס נסה py -3 --version, ואם אין אז python --version. בכל הפקודות למטה השתמש בזו שעבדה. אם אין אף אחת, עצור ואמור לי בשורה אחת להתקין Python מ-python.org (בווינדוס לסמן בהתקנה Add python.exe to PATH) ולהדביק את ההודעה הזו שוב.
3. הורד את הקובץ https://themakers.co.il/map/agent-map.zip לתיקייה זמנית (curl -fsSL, עם הפלט מופנה לקובץ, או עם Python).
4. בדוק שהקובץ שלם: טביעת ה-sha256 שלו חייבת להיות בדיוק 00b7d2193430b6413d5f9f7149a299accd6daf1e436fe2632ce546297836dab0
   אם היא שונה, עצור, מחק את הקובץ, ואמור לי שההורדה לא תקינה. אל תתקין קובץ עם טביעה אחרת.
5. אם כבר יש תיקייה בשם agent-map בתיקיית הסקילים, מחק אותה קודם (החילוץ ממזג קבצים ולא מחליף). אחר כך חלץ עם Python: python3 -m zipfile -e <הקובץ> <תיקיית הסקילים>. נוצרת תיקייה בשם agent-map ובה SKILL.md.
6. בדוק: קרא את 5 השורות הראשונות של SKILL.md, והרץ python3 <התיקייה>/scripts/build_map.py --help. הוא אמור להדפיס הסבר קצר ולצאת בלי שגיאה.
7. מחק את קובץ ה-zip הזמני.
8. אמור לי בעברית, בשלוש שורות: איפה הסקיל הותקן, שצריך לסגור ולפתוח מחדש את הכלי כדי שהוא ייטען, ושאחרי זה אני כותב "תבנה לי את המפה שלי", עונה על שש שאלות, ומקבל עמוד עם שלושת הסוכנים הראשונים לעסק שלי.

אל תפעיל את הסקיל עכשיו ואל תבנה מפה. רק התקנה.
