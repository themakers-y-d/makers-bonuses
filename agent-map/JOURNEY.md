# מסע הלקוח · סקיל המפה

קהלים: קהל-קר
פלטפורמות: מק, ווינדוס
סוג: התקנה
הבטחה: תוצר

**התוצאה במשפט אחד:** בסוף יש לו עמוד מעוצב אחד עם שלושת הסוכנים הראשונים לעסק שלו לפי סדר בנייה, מה כל אחד מחליף, כמה זמן חוזר אליו לפי המספרים שהוא עצמו נתן, הצעד הראשון להיום, והמשפט שפותח מחר את הבנייה של סוכן 1. והסקיל נשאר אצלו ב-Claude לעדכון המפה.

הקהל הוא מי שהגיב "מפה" על הפוסט. בעל עסק קטן, לא טכני, שמע שצריך "לבנות סוכנים" ולא יודע מאיפה להתחיל. הכאב, מילה במילה מהפאנל: "לא צריך לשכנע אותי, רק תסביר איך אני אשתמש בזה בעסק שלי". רוב הקהל הזה עובד באפליקציה של Claude או באתר, ולכן זו הדלת הראשית. מי שיש לו Claude Code או Codex מקבל דלת שנייה.

ההבדל בין מק לווינדוס הוא רק בהורדה: בספארי במק קובץ zip לפעמים נפתח לבד לתיקייה, ואז מכווצים אותה בחזרה. באפליקציה של Claude הסקריפט רץ בסביבה של Claude, לא על המחשב שלו. ב-Claude Code או Codex הוא רץ על המחשב, וצריך Python 3 בלבד, בלי ספריות (בווינדוס `py -3` או `python`, והפתיחה בדפדפן דרך `os.startfile`).

## שבע השאלות, בנעליים שלו

1) מאיפה הוא מגיע ומה הוא יודע. מתגובה "מפה" על פוסט, בטלפון. הוא יודע לשוחח עם Claude, אבל לא העלה סקיל מעולם. לכן הדף אומר מה זה סקיל ואיפה בתפריט נמצא Skills.

2) הדבר הראשון שהוא רואה: "רוצה לבנות מערכת סוכנים משלך?", ואחריו הכותרת "המפה שלכם: אילו שלושה סוכנים לבנות קודם בעסק".

3) איפה הוא עלול לעצור. בטלפון, כי ההעלאה עובדת מהמחשב. במתג "Create and edit files", שבלעדיו המפה יוצאת כטקסט. בספארי במק. ובשאלת השעות, ולכן הדף אומר מראש שהערכה גסה מספיקה ולמה כדאי לתת אותה.

4) מה רק הוא יכול לעשות. להעלות את הקובץ, לענות על השאלות, ולעשות את הצעד הראשון.

5) מה קורה אם הוא עוצר באמצע. הקובץ נשאר בהורדות, הדף זוכר שנרשם, והשיחה ממשיכה מאותה שאלה ("תמשיך").

6) איך הוא יודע שזה עבד. עמוד עם השם של העסק שלו, שלושה סוכנים שהוא מזהה מהעבודה שלו, ו"מה סיפרתם לי" בתחתית.

7) מה קורה בפעם הבאה. "תעדכן את המפה שלי" אחרי שסוכן 1 עובד: הוא יורד מהמפה והבאים זזים למעלה.

## השאלה השמינית, ממה יש לו אפס ביום הראשון

אפס עסק: שלב 1 עוצר בעדינות ולא בונה מפה ריקה (נבדק, הרצה nobiz). אפס מספרי שעות: המפה כותבת "לא הערכתי" ולא ממציאה (נבדק, הרצה nohours). אפס כלים: הסוכנים נבנים עם מה שהוזכר בלבד. אפס Python, רק ב-Claude Code או Codex: הודעת ההתקנה עוצרת ואומרת מה להתקין.

## דרך החזרה

ב-Claude, ב-Customize ואז Skills, מכבים או מוחקים את agent-map. ב-Claude Code או Codex מוחקים את התיקייה `agent-map` מתיקיית הסקילים.
