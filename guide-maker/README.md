# סקיל המדריכים

סקיל שכותב מדריכים ומגנטי לידים לעסק שלכם, בצבעים ובשם של העסק, ברמה שאפשר לשלוח ללקוחות עוד היום. נכתב ל-Claude Code ול-Codex. נבדק במק עם Claude Code. נכתב גם לווינדוס ול-Codex, ועדיין לא רץ שם.

## מה הוא עושה

אתם מספרים לו על העסק בכמה משפטים. הוא שואל בהודעה אחת את מה שצריך כדי שהקובץ ייצא מוכן לשליחה: השם, הוואטסאפ ושתי שורות עליכם. אם אין לכם נושא, הוא מציע חמישה רעיונות באותה הודעה.

אחר כך הוא כותב, מעביר את הטיוטה לעורך שקורא אותה כמו זר ופוסל אותה, ומתקן. בסוף אתם מקבלים קובץ אחד מעוצב, עם כפתור וואטסאפ אליכם, שנשמר כ-PDF בגודל מסך טלפון ונשלח בוואטסאפ.

## איך מתקינים

1. פותחים את הקובץ [INSTALL.md](INSTALL.md) ולוחצים על כפתור ההעתקה בפינה העליונה של הקובץ. רק בכפתור, לא בסימון עם העכבר, כי סימון מעתיק גרסה שבורה.
2. מדביקים לקלוד קוד או לקודקס. הוא מתקין את הסקיל לבד. אם הוא מבקש אישור לכתוב לתיקיית ההגדרות שלו, מאשרים.
3. סוגרים ופותחים מחדש את הכלי, וכותבים "תכין לי מדריך". בזמן העבודה הוא יבקש אישור לשמור את המדריך ולפתוח אותו בדפדפן. בבקשת השמירה הראשונה בוחרים באפשרות שמאשרת את כל העריכות, ולא תישאלו שוב.

הסקיל עצמו נמצא ב-[skills/guide-maker/SKILL.md](../skills/guide-maker/SKILL.md), למי שרוצה לקרוא או לשנות.
