# סוכן המדריכים

סוכן שכותב מדריכים ומגנטי לידים לעסק שלכם, ברמה שאפשר לשלוח ללקוחות עוד היום. עובד ב-Claude Code וב-Codex.

## מה הוא עושה

אתם מספרים לו על העסק בכמה משפטים. אם אין לכם נושא, הוא מציע חמישה רעיונות למדריך, כל אחד עם נימוק, ואתם בוחרים.

אחר כך הוא כותב, מעביר את הטיוטה לעורך שקורא אותה כמו זר שלא מכיר את העסק ופוסל אותה, ומתקן. בסוף אתם מקבלים קובץ HTML מעוצב אחד, שנפתח בדפדפן ואפשר לשמור כ-PDF.

## איך מתקינים

1. פותחים את הקובץ [INSTALL.md](INSTALL.md) ולוחצים על כפתור ההעתקה בפינה העליונה של הקובץ.
2. מדביקים לקלוד קוד או לקודקס. הוא מתקין את הסוכן לבד. אם הוא מבקש אישור לכתוב לתיקיית ההגדרות שלו, מאשרים.
3. סוגרים ופותחים מחדש את הכלי, וכותבים "תכין לי מדריך".

הסקיל עצמו נמצא ב-[skills/guide-maker/SKILL.md](../skills/guide-maker/SKILL.md), למי שרוצה לקרוא או לשנות.

## ממי זה

מבית MAKERS, הסדנה שבונה לכם צוות סוכנים שעובד בשבילכם: [themakers.co.il](https://themakers.co.il)
