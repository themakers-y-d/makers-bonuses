1. בדוק באיזה מחשב אתה, בלי לשאול אותי: הרץ uname -s. Darwin זה מק, ו-MINGW, MSYS או CYGWIN זה ווינדוס עם Git Bash, ושניהם ממשיכים לסעיף 2. אם הפקודה נכשלת, אתה בווינדוס ב-PowerShell בלי Git for Windows, והעורך צריך אותו: אמור לי את זה במשפט אחד ובקש אישור. אחרי שאאשר, הרץ ב-PowerShell winget install --id Git.Git -e --source winget --accept-package-agreements --accept-source-agreements (אם winget חסר, תן לי את הקישור https://git-scm.com/download/win). בסוף אמור לי לסגור לגמרי את קלוד קוד, לפתוח אותו שוב ולהדביק את ההודעה הזו מחדש, ועצור.
2. אמור לי בשורה אחת שייתכן שאתבקש לאשר כתיבה לתיקיית ההגדרות של קלוד ולהריץ פקודות, ושזה רגיל. אחר כך הרץ את הפקודה הזו בדיוק כמו שהיא. היא מורידה את ארבעת הקבצים של הסקיל מגרסה קבועה, ובודקת את טביעת האצבע של כל אחד:
