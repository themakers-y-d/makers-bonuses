# המתנות של MAKERS

תיקיות מוכנות להתקנה, כל אחת נותנת לקלוד שלכם יכולת אחת חדשה ואמיתית. הכל בבעלות מלאה שלכם: הקוד אצלכם, הנתונים אצלכם, בלי מנויים.

## מה יש כאן

### אוטומציית DM באינסטגרם · [ig-dm-automation](ig-dm-automation/)

מישהו מגיב מילה על ריל שלכם, ומקבל אוטומטית הודעה פרטית עם הלינק שביקש. זה מה שכלים בתשלום עושים במנוי חודשי, וכאן זה שלכם. ההתקנה היא הודעת הדבקה אחת לקלוד קוד, וההדרכה המלאה בעמוד: [themakers.co.il/ig-dm](https://themakers.co.il/ig-dm)

### צינור תמלולים · [transcript-pipeline](transcript-pipeline/)

כל פגישה שאתם מקליטים ב-Wispr Flow עולה כל לילה ל-Google Drive, ובבוקר נספגת לתוך הזיכרון של הסוכנים שלכם: מי היה בחדר, מה נסגר, ומה כל סוכן צריך ללמוד. הצוות מתעדכן לבד מהפגישות שלכם, בלי להעתיק שום דבר ביד. ההתקנה היא הודעת הדבקה אחת לקלוד קוד.

מתנות נוספות יתווספו כאן.

## ממי זה

מבית MAKERS, הסדנה שבונה לכם צוות סוכנים שעובד בשבילכם: [themakers.co.il](https://themakers.co.il)
